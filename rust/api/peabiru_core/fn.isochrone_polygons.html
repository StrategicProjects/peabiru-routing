pub fn isochrone_polygons(

Expand description

Polygon isochrones from a travel-time surface: for each origin, each percentile and each cutoff, the cells reached in less than the cutoff, traced by isoband’s marching squares over the cell centres (isoband::isobands() from 0 to the cutoff), converted to longitude and latitude and grouped into polygons with holes (isoband::iso_to_sfg()).

cutoffs are checked by isochrone_cutoffs. Every (origin, percentile, cutoff) gets one result, ordered by origin, percentile (ascending) and cutoff (descending). RouteError::Invalid for bad cutoffs, and where isoband stops: two rings whose relation it cannot decide.

The order of the rings in each band and the vertex each ring starts at are those isoband gives where this crate runs: isoband walks a C++ hash table, whose order is that of the C++ standard library it was built with, libc++ on macOS and libstdc++ on Linux and Windows. This function follows the target it is compiled for (libc++ on Apple targets and on WebAssembly, libstdc++ elsewhere), so on each platform the polygons are those the R package isoband makes there.
