Expand description

Write itineraries to CSV files (output_dir): one file per pair with itineraries, <dir>/from_<origin id>_to_<destination id>.csv, with the number formats of CsvOutput: with osm_link_ids (the itineraries routed with it) osm_id_list, edge_id_list, board_stop_id and alight_stop_id after route, and the geometry column (the WKT text of ItineraryLeg::wkt) last unless drop_geometry. ids and points are those of the pairs given to detailed_itineraries ((from_id, to_id) and ((lat, lon), (lat, lon))).

The file names are built from the ids: an id holding a path separator (/, \\) or NUL (on Windows also < > : " | ? * or a control character) is an error of kind InvalidInput, before anything is written.
