pub fn isochrone_lines(

    minutes: &[Option<u32>],
    cutoffs: &[f64],
) -> Result<Vec<IsochroneLine>, RouteError>
Expand description

Line-based isochrones from a travel-time matrix to the edges’ centroids: minutes holds one row per origin and one value per row of the StreetEdges (the median travel time, None where unreached or beyond the trip limit), and cutoffs are checked by isochrone_cutoffs.

Times of 0 are left out; each other edge gets the band (a, b] of consecutive cutoffs (starting from 0) holding its time, and edges beyond the last cutoff are left out. The result is ordered by origin, then by band and travel time, both descending, ties in edge order. RouteError::Invalid for bad cutoffs or a matrix of the wrong size.
