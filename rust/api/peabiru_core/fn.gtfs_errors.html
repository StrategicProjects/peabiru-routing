pub fn gtfs_errors(
    name: &str,
    zip: &[u8],
) -> Result<Vec<GtfsFeedError>, NetworkError>
Expand description

The errors the validator gtfs-lib (Conveyal) records while loading the GTFS feed whose .zip is zip (one feed; call it once per feed). name names the feed in errors.

Every check of gtfs-lib’s table loaders and of its PostLoadValidator is made, and the errors are listed by table, in gtfs-lib’s loading order, then by line. An error when the zip cannot be read, when gtfs-lib would fail on the feed instead of listing its errors, and for a locations.geojson (GTFS-Flex zones) that is not in UTF-8.
