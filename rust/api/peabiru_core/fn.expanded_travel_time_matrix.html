Expand description

Every trip of the departure window, minute by minute, with the routes ridden: per origin, the rows ordered by destination, departure minute and draw. For each departure minute the transit records come first in PATH_ORDER, numbered 1.., then the remaining draws repeat the walk-only record (or an unreachable, NA one) up to the draws per minute (populateTravelTimesBreakdown). A destination with no record at all has no rows. Points are (lat, lon) degrees; p.percentiles are not used.

RouteError::Invalid when the network has no public transport, the parameters are invalid (see TransitParams::validate) or there are more than 5,000 destinations; RouteError::Cancelled when p.cancel is cancelled before every origin is done.
