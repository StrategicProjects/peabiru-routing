Expand description

Detailed itineraries between each origin and the destination of the same index (origins[i] to destinations[i], (lat, lon) degrees; pair the points beforehand for every origin to every destination): per pair its itineraries (the trip by the street mode alone first, then by number of legs and duration), none when no trip is found.

Without public transport (p.transit_modes empty) the itinerary is the street path by p.mode. With it, the network must have public transport; with shortest_path and no fare structure the result is the faster of the direct trip and the fastest public transport trip over the window (FastRaptor), otherwise the trips McRAPTOR finds, with their fares when p.fare_structure is given. Errors: invalid parameters, a network with frequency-based trips, cancellation, and the rare cases noted in the error message that cannot be routed reproducibly. The notes of detailed_itineraries_noted are dropped.
