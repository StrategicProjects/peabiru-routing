Expand description

The latest trip that arrives by a given time. p must already hold the departure side of the search: the service date and departure from arrival_departure and time_window = max_trip_duration. For each destination the latest departure minute with a record arriving by departure + max_trip_duration wins: its first transit record in PATH_ORDER, else the walk-only record (filterLatestBeforeArrivalTime, offs 31-266). At most one row per destination. Errors as expanded_travel_time_matrix, and RouteError::Invalid when p.time_window is not p.max_trip_duration.
