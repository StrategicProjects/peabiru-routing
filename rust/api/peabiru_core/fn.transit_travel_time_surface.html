Expand description

Travel-time surface by public transport (its modes, access and egress as in TransitParams), at each of p.percentiles over the departure window. p.max_trip_duration is the search limit (for isochrones, the largest cutoff plus 10 minutes). Otherwise as street_travel_time_surface, and RouteError::Invalid when the network has no public transport.
