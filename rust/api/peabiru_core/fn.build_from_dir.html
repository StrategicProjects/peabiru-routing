pub fn build_from_dir(
    dir: impl AsRef<Path>,
    opts: &BuildOptions,
) -> Result<Network, NetworkError>
Expand description

Build a network from a directory holding one OpenStreetMap .pbf file and any number of GTFS .zip feeds, and link the stops to the streets; with BuildOptions::elevation, apply slope costs from the directory’s .tif raster (see build_from_bytes_with_elevation for the rasters supported).

Files are recognised by their extension in lower case only (.pbf, .zip); with several .pbf files the last one listed is used, and the feeds are loaded in the order the operating system lists them (see build_from_bytes). A directory without GTFS feeds gives a network without public transport (Network::transit is None), good for street routing only.

The build fails when a feed has GTFS errors of priority HIGH, or is one gtfs-lib cannot load at all (NetworkError::high_priority_gtfs_errors, gtfs_errors), unless BuildOptions::ignore_gtfs_errors is set; what the build has to say about the feeds and the raster is in Network::build_warnings.

This reads the files and builds the network as build_from_bytes does from the same bytes, with the feeds in the directory’s order; errors name the files by their path.
