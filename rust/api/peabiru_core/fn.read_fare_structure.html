pub fn read_fare_structure(
    bytes: &[u8],
    encoding: &str,
) -> Result<FareStructure, RouteError>
Expand description

The fare structure in the bytes of a fare structure .zip file: the global settings (the counts made integers as as.integer() does: Inf becomes NA, NaN here), the three tables with their known columns, and the debug settings. encoding is fread’s: "UTF-8" (the default) and "unknown" read the text as UTF-8, "Latin-1" as ISO 8859-1.
