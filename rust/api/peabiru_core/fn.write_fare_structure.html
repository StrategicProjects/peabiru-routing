The bytes of a fare structure .zip file. The five CSV files in it are byte for byte what data.table::fwrite() writes on the same platform (its line ends: \r\n on Windows, \n elsewhere, and in WebAssembly); the archive deflates them and leaves them undated (see the module notes).
