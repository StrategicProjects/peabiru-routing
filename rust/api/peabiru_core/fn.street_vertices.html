pub fn street_vertices(network: &Network) -> StreetVertices

The street vertices at an end of some edge (see StreetVertices), in the iteration order of the hash set they are collected in while walking the edges, which is the same on every platform: by bucket of the set’s final table (the vertex index spread as h ^ (h >>> 16)), and within a bucket in the order they were added.
