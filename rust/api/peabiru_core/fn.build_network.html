Expand description

Read an OpenStreetMap .pbf file and build the street network for walking, cycling and driving, without public transport (Network::transit is None; see build_from_dir for a network with GTFS feeds).

A file that cannot be read or decoded, or that gives no street edge at all (empty, a header only, or no routable way), is an error naming the file. BuildOptions::elevation needs a raster, so it is not used here (see build_from_bytes_with_elevation).
