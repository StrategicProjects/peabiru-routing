Expand description

Accessibility by a street mode alone (WALK, BICYCLE or CAR): one unvarying travel time per destination, so every percentile gets the same value (TravelTimeReducer.recordUnvaryingTravelTimeAtTarget). params.max_trip_duration is the search limit, and percentiles are checked as validate_percentiles does. Errors as transit_accessibility.
