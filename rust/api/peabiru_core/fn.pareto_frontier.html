Expand description

The trade-off between travel time and fare. For every cutoff of fare_cutoffs, in the order given, the travel times are those of the multi-criteria router (McRAPTOR, see TransitParams::fare_structure) with max_fare set to the cutoff (p.max_fare is not used); a destination and percentile gets a row at each cutoff where its travel time differs from that of the previous cutoff with a row, and is below max_trip_duration.

p.fare_structure is required. draws_per_minute is 1 whatever p.draws_per_minute says, so that time_window departure times are sampled. With p.transit_modes empty the trip is by p.mode alone: the street travel time, the same at every cutoff, with p.max_trip_duration as the limit (lower it to the mode’s own limit first); otherwise the network must have public transport (RouteError::Invalid). Points are (lat, lon) degrees.
