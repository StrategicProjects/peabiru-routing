pub fn locate_facilities(
    costs: &CostTable,
    demand: &[f64],
    params: &LocationParams,
) -> Result<LocationSolution, RouteError>
Expand description

Choose where to open facilities.

costs gives the minutes from each demand point to each site; demand the weight of each demand point (residents, pupils…), which must be finite and not negative. The sites in LocationParams::existing are already open; all the others are candidates. See LocationModel for the four models, LocationParams for what can be set and LocationSolution for what comes back.

The models are solved by greedy construction followed by vertex substitution: the solution is good and reproducible, not proven optimal. For maximal covering the greedy coverage of the demand the existing facilities leave uncovered is at least 1 - 1/e (63%) of the best possible. In set covering and p-center the points with weight 0 are not demand; the others count the same whatever their weight.

Errors: RouteError::Invalid for weights that do not match the table, a negative or non-finite weight, an index in existing outside the table or repeated, no candidate, n_facilities of 0 or more than the candidates, or a covering model without a cutoff; RouteError::Cancelled.
