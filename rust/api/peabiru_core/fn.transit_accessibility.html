Accessibility by public transport (the modes, access and egress as in transit_travel_time_matrix). Opportunity counts that are zero, negative or NaN contribute nothing (TravelTimeReducer.java:251-253). p.percentiles are the travel-time percentiles; p.max_trip_duration and p.max_walk_time must already be the limits of the search (for the step function max_trip_duration is the largest cutoff, set before deriving the walk limit; see accessibility_trip_limits).

Every origin gets a value for every (opportunity, percentile, cutoff), 0 when nothing is reachable or the origin cannot be linked. Points are (lat, lon) degrees. RouteError::Invalid when the network has no public transport, or the parameters, cutoffs or opportunity columns are invalid, RouteError::Cancelled when p.cancel is cancelled before every origin is done.
