Isochrones in the browser

The isochrones on this map are computed here, in your browser, by the peabiru npm package compiled to WebAssembly: the network is built from an OpenStreetMap extract and GTFS feeds, and every click routes from the point you chose. No routing request leaves the page.

How this page works

The page loads the peabiru npm package as a plain ES module, fetches the .pbf and GTFS .zip files of the city, and calls buildNetwork() once. Each click calls isochrone() with the chosen mode and cutoffs and hands the GeoJSON polygons to MapLibre GL JS, which draws them and lets the map be dragged and zoomed. The background map is there to recognise the city: its tiles come from OpenFreeMap, the only requests the page makes after loading (they say which part of the map is on screen, never where you clicked). Switch it off and the map is the street network peabiru built, as returned by isochrone(…, { polygonOutput: false }): the thin lines that also show, under the background map, where the network ends. Public transport uses the median of the departures in the 10 minutes from the chosen time; the Porto Alegre bus feed only has trips from late morning to early evening, so pick a time between 12:00 and 17:00 there. Recife and Caruaru have streets only: no open GTFS feed was found for either, so public transport is not offered there; their extracts are Recife's municipality, as cut by IBGE's boundary, and Caruaru's urban area (14 × 12 km around the centre), without buildings (the Recife and Caruaru example explains how they are made). No elevation raster is used here, so walking and cycling on Caruaru's hills are faster than in reality. The code is in site/demo, and the JavaScript guide walks through it.
