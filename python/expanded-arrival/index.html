    Expanded and arrival matrices¶

    These two functions report individual trips rather than percentiles. Both route by public transport (mode=["WALK", "TRANSIT"] by default here, or any subset of the transit modes reached and left on foot, by bicycle or by car); a street mode alone is an error (use travel_time_matrix()).

    import datetime as dt

import peabiru

network = peabiru.build_network(peabiru.sample_data_path(), n_threads=2)
points = peabiru.sample_points()

    Expanded matrices¶

    expanded_travel_time_matrix() gives the travel time of the trip found for every departure minute of time_window and, with frequency-based GTFS, for every Monte Carlo draw (draws_per_minute, 5 by default). With breakdown=True each trip is split into access, waiting, in-vehicle, transfer and egress times, and the number of rides:

    ettm = peabiru.expanded_travel_time_matrix(
    network, points.iloc[:2], points,
    mode=["WALK", "TRANSIT"],
    departure_datetime=dt.datetime(2019, 5, 13, 14, 0),
    time_window=2,
    breakdown=True,
    seed=42,
    n_threads=2,
)
print(ettm.dtypes)
trips = ettm[ettm["n_rides"] > 0]
cols = ["to_id", "departure_time", "draw_number", "wait_time", "ride_time",
        "routes", "total_time"]
print(trips[cols].head().to_string())

    Times are minutes with one decimal (float64). routes joins the route ids of the rides with "|", or is "[WALK]" for a trip on foot. Trips longer than max_trip_duration are kept with missing values: NaN times, None routes and <NA> rides.

    short = peabiru.expanded_travel_time_matrix(
    network, points.iloc[:3], points,
    mode="TRANSIT",
    departure_datetime=dt.datetime(2019, 5, 13, 14, 0),
    time_window=2,
    max_trip_duration=8,
    breakdown=True,
    seed=1,
    n_threads=2,
)
print(short[short["total_time"].isna()][["to_id", "routes", "n_rides", "total_time"]].head(3))

    Arrival matrices¶

    arrival_travel_time_matrix() finds, for each origin and destination, the trip that leaves latest and still arrives by arrival_datetime: departures are searched minute by minute from arrival_datetime - max_trip_duration.

    attm = peabiru.arrival_travel_time_matrix(
    network, points.iloc[:2], points,
    mode=["WALK", "TRANSIT"],
    arrival_datetime=dt.datetime(2019, 5, 13, 15, 0),
    max_trip_duration=30,
    seed=42,
    n_threads=2,
)
cols = ["from_id", "to_id", "departure_time", "routes", "total_time"]
print(attm.sort_values("total_time", ascending=False)[cols].head().to_string())

    Around midnight and time zones¶

    The search window may start on the day before; departure times after midnight are then written past 24:00:00:

    late = peabiru.arrival_travel_time_matrix(
    network, points.iloc[:1], points.iloc[:4],
    mode="TRANSIT",
    arrival_datetime=dt.datetime(2019, 5, 14, 0, 20),
    max_trip_duration=30,
    seed=42,
    n_threads=2,
)
print(late[["to_id", "departure_time", "total_time"]])

                 to_id departure_time  total_time
0  89a8100c00fffff       24:19:00         0.4
1  89a8100c007ffff       24:12:00         7.3
2  89a8100c077ffff       24:09:00        10.9
3  89a8100c03bffff       24:11:00         8.8

    arrival_datetime - max_trip_duration is computed as R computes it with a POSIXct: on the absolute time for a timezone-aware datetime (so a daylight-saving change in between is accounted for) and then read in the datetime's own zone; on the clock time for a naive datetime.
